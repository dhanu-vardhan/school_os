## Analytics (Part 8, 2026-11-17)

- **Classification:** school aggregates are `internal`; pseudonymous student-level rows are
  `confidential-minor`; chronic/support-flag lists are `confidential-minor` + `TODO(DPO review)`.
- **Tenant isolation:** every V6 analytics table has `school_id`, `ENABLE` + `FORCE` RLS and the
  same `school_isolation` policy as operational tables. The runtime role has SELECT only; tenant
  binding stays transaction-local (`set_config`, never a session-level `SET`).
- **Aggregate first:** dashboards and Explore start from aggregates. Student-level drill-down is
  gated by `analytics.student`, scope-checked from the JWT/membership, and recorded in an
  append-only audit event (actor, metric, scope, timestamp; no values).
- **Small cells:** `n < 5` is suppressed before serialisation on every series, table, matrix and
  drill-down view to prevent differencing. The threshold is configurable 3–20 by head/admin only
  (`docs/DECISIONS.md`, A8-3).
- **No sensitive dimensions:** no ethnicity, religion, health, disability or safeguarding
  dimension exists in the analytics contract. Gender/age-band are not exposed in the current
  slice. There is no `teacher_id` in any analytics response and no staff ranking.
- **Profiling-like features:** chronic-absence flag, support composite and fairness panel are
  DPO-review gated and disabled for real data. Language is supportive ("needs support"), never a
  label or an automated decision.
- **Exports:** step-up + `analytics.export` required and audited. The governed facade
  (`POST /api/analytics/exports`) starts an async job with a "Confidential · generated by ·
  timestamp" watermark, idempotency key and job status endpoint; the legacy
  `POST /api/v1/analytics/export` returns a CSV text envelope with `sourceAvailable` in `meta`.
  The demo adapter mirrors the async job contract. Object storage, XLSX/PDF renderers and the
  designed fresh-per-export pseudonym salt remain gaps (`docs/GAP_REPORT.md`, A7); no fabricated
  download URL is returned.
- **France:** statistics on sensitive attributes are restricted. Any future gender/age/support
  breakdown requires `TODO(legal-review)` and DPO sign-off before enabling.
- **Demo boundary:** all demo analytics numbers are synthetic and flagged `meta.mock=true`;
  they are not stored in tenant tables and must never be presented as school data.
